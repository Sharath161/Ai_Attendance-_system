Works on low data

Most face systems need dozens of images per person. This one hits 97.5% top-1 across 120 identities from a single enrolment photo, and 98.5% from two.

Runs on cheap hardware

A 13.6 MB model on plain CPU — no GPU required. Thread pinning, detection downscaling and an optional INT8 build target Raspberry-Pi-class devices.

🌍

Works everywhere

Plain HTTP with CORS. Multipart or JSON+base64, so the same API drives web, iOS, Android and desktop clients with no SDK lock-in.

Three calls. That's the whole API.

Enrol a subject, then identify or verify. Everything else is optional.

1

Enrol

Send one or more photos with a subject ID. The service detects, aligns and stores 512-d embeddings.

2

Identify

Send a photo, get the matching subject back with a confidence score and ranked candidates (1:N).

3

Verify

Or check a photo against one known subject and get a yes/no with a score (1:1).

# enrol a subject from one photo
curl -F subject_id=alice -F name=Alice -F images=@alice.jpg \
     http://localhost:8080/enroll

# identify an unknown face
curl -F image=@query.jpg http://localhost:8080/identify
# → {"status":"matched","match":{"subject_id":"alice","score":0.86}}
